		ໂຄງສ້າງ VB.NET ຂອງ OOP Polymorphism :
		
		Public Class ຊື່ຂອງຄລາສ BaseClass
		      Public Overridable Sub Show()
			     Console.WriteLine("ຈາກ BaseClass")

		      End Sub
		      End Class

		Public Class ປະກາດຄລາສທີ່ໄດ້ຮັບມາ DerivedClass
		        Inherits ຈູດອ້າງອີງທີ່ມາ BaseClass
		    Public Overrides Sub Show()
			Console.WriteLine("ຈາກ Derived Class")

		    End Sub
		End Class
