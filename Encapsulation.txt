=> ຮູບແບບ OOP ແບບ Encapsulation ຄື : ການເຊື່ອງຂໍ້ມູນໄວ້ພາຍໃນວັດຖຸ ຕົວແປ ແລະ ເປີດເຜີຍສະເພາະສິ່ງທີ່ຈຳເປັນອອກມາ ຜ່ານ Property ແລະ Method ຫຼືເວົ້າງ່າຍຄື​ : ບໍ່ໃຫ້ຄົນນອກສາມາດມາແກ້ຄ່າພາຍໃນໂດຍຕົງໄດ້.
	  => ໃຊ້ໄວ້ເຮັດຫຍັງ : 
			1. ໃຊ້ໄວ້ເພື່ອຄວບຄຸມການເຂົ້າເຖິງຂອງຂໍ້ມູນ.
			2. ປ້ອງກັນການປ່ຽນແປງຄ່າຜິດພາດ ເຊັ່ນ : ເງີນເດືອນພະນັກງານຈະຕ້ອງບໍ່ຖືກແກ້ໂດຍຕົງຈາກໃຜກໍໄດ້
	 => ເຫດຜົນທີ່ຕ້ອງໃຊ້ OOP Encapsulation :
			1. ປ້ອງກັນຂໍ້ມູນຖືກປ່ຽນໂດຍບໍ່ໄດ້ຕັ້ງໃຈ
			2. ຄວບຄຸມກົດຂອງຂໍ້ມູນໄດ້
			3. ເຮັດໃຫ້ການຮັກສາລະບົບງ່າຍຂື້ນ ປ່ຽນ Logic ໄດ້ໂດຍບໍ່ກະທົບໂຄ້ດອື່ນ

	ໂຄງສ້າງ :​
		Public Class ໃສ່ຊື່ຂອງຄລາສແມ່
		   --- ຕົວແປພາຍໃນ (Private)
			Private _fieldname As DataType

		   --- Property ສຳຫຼັບການເຂົ້າເຖິງຂໍ້ມູນແບບປອດໄພ
		Public Property ຊື່ຟິວຂໍ້ມູນ As DataType
		      Get
			 Return _ຊື່ຟິວຂໍ້ມູນ
		            End Get
		      Set(value As DataType)
			  ''' ໃສ່ເງື່ອນໄຂກວດສອບກ່ອນປ່ຽນຄ່າ
			     If (value <> Nothing ) Then
			      _fieldname = value
			  Else
			      Throw New Exception("ຂໍ້ມູນບໍ່ຖືກຕ້ອງ")
			    End If
		    End Set
		End Property
	     End Class
